Colour Piano Staves

The same tunes as Colour Piano Sheets, written on a real music stave: each note is its coloured shape sitting on the right line or space, with stems, beams and dots showing how long it lasts. Type a tune with note letters and the stave is drawn for you. Tap Listen and the page listens to the piano through the microphone: the note to play glows, and it moves on each time the right note is played. The colours match the book: C red, D orange, E yellow, F green, G light blue, A pink, B purple. The shape shows which part of the piano: circles from middle C, stars above, hearts below, stars again below that, and a heart for the very top C. Black keys are triangles and squares, taking turns each octave, with triangles around middle C.

How Listen works

Tap Listen and allow the microphone when the browser asks. Put the phone, tablet or computer near the piano. The note to play next glows. When the piano plays that note, the glow moves on to the next one. Wrong notes are ignored, so just try again. A note played twice in a row needs two separate presses. Tap any note on the sheet to start from there. Listen follows the tune (the right hand); it is happy with the right letter in any octave.

How to write notes

C' D' E'The next C and up (stars)
C''The very top C (heart)
C, D, E,The C below middle C and up (hearts)
C,, D,, E,,Two Cs below middle C and up (stars)
G- C---Hold longer: each dash adds a beat. On the stave, a long note has an open shape (a white middle): 2 beats with a stem, 4 beats without
E~A quick note (half a beat): a stem with a flag, or joined to its neighbours by a beam
F#.A dotted note (one and a half beats)
E,~*A melody note the left hand plays. Shown with a small L when only the right hand is shown; a rest in the right hand when both hands are shown. Use ** if the right hand holds its previous note there instead
A-+A~A tie: one note held for both lengths added together (here 2½ beats)
F.~ A~~A dotted quick note (¾ beat) then a very quick note (¼ beat)
F# BbBlack keys (sharps and flats). Triangles in the middle C octave and the lowest one, squares in the other two
rA rest (a gap)
|Bar line
C,---A typical bass note: the C below middle C, held for 4 beats
/ or new lineStart a new line on the sheet
Move the tuneMoves every note in both hands up or down. "Starts on" moves it so the first note is the key you pick. "In the key of" moves it into the key you pick
_ in wordsLeave that note without a word
